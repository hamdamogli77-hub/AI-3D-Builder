# AI 3D Builder

**AI-powered 3D model creation desktop application**

AI 3D Builder is an experimental project focused on making 3D modeling easier through artificial intelligence.

## Features

- Image-based 3D modeling workflow
- Text-based object description
- Multi-view image input
- Interactive 3D workspace
- Basic model editing
- Local project saving
- OBJ model export

## Current Development Status

This project is currently an HTML prototype.

Basic interface and local demo modeling features are available. Real AI-powered 3D generation requires a secure backend integration.

## Technologies

- HTML5
- CSS3
- JavaScript
- 3D visualization

## Goals

- Build a Windows desktop application
- Integrate AI-powered 3D generation
- Support multiple image inputs
- Improve 3D editing tools
- Enable professional 3D model exports
